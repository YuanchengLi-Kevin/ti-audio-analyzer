# Real-Time Audio Spectrum Visualizer

This project is a real-time audio spectrum visualizer for an MSPM0G3507 LaunchPad attached with a BOOSTXL-AUDIO Boosterpack and ILI9341 LCD.

## Hardware

- TI MSPM0G3507 LaunchPad
- BOOSTXL-AUDIO Boosterpack
- ILI9341 LCD (COM-28379 Sparkfun)
